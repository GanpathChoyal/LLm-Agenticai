# Cardiac Emergency AI

An AI-powered cardiac emergency assistance system designed to support users in identifying potential cardiac emergencies and providing appropriate next-step guidance using an agentic AI workflow.

## Features

* AI-powered cardiac emergency assessment
* Agent-based reasoning and decision support
* Natural language interaction
* Emergency-focused recommendations
* Structured response generation
